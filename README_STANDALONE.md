# Endless Dark Square — автономная версия

Этот каталог содержит исходники игры, локальные изображения и конфигурацию запуска. В игровых исходниках нет внешних ссылок на изображения, аналитику или веб-шрифты.

## Что находится в архиве

| Путь | Назначение |
|---|---|
| `client/public/assets/` | Три изображения, которые используются игрой при запуске. |
| `assets/source-art/` | Все исходные художественные изображения проекта. |
| `client/src/` | React-интерфейс, игровая сцена и логика. |
| `server/` | Локальный сервер разработки. |

## Запуск

Нужен Node.js 22 или новее и пакетный менеджер `pnpm`.

```bash
pnpm install
pnpm dev
```

Затем открой адрес, который выведет Vite. Для production-сборки выполни:

```bash
pnpm build
pnpm start
```

> Зависимости не вложены в архив, чтобы не раздувать его на сотни мегабайт. После `pnpm install` игра использует только локальные изображения из архива.
