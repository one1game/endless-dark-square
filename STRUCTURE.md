# Структура Endless Dark Square

```text
client/src/
├── App.tsx                         # Только полноэкранный GameCanvas на маршруте /
├── components/GameCanvas.tsx        # React-рамка: Babylon Engine + DOM-слой джойстика
├── game/
│   ├── scene.ts                     # Вход сцены, GameHandle и жизненный цикл мира
│   ├── GameWorld.ts                 # Частицы, центральный квадрат, обновление и режим demo
│   └── InputManager.ts              # Семантический вектор движения от клавиатуры и джойстика
└── index.css                        # Полноэкранный тёмный каркас, типографика и слои управления
```

## Владение состоянием

| Объект | Ответственность | Создаёт / удаляет |
|---|---|---|
| `GameCanvas` | Создаёт один Babylon Engine, связывает DOM-джойстик с `InputManager`, очищает слушатели | `GameWorld` и Engine |
| `InputManager` | Хранит вектор движения, объединяет касание и клавиши | Слушатели клавиатуры |
| `GameWorld` | Владеет центральным квадратом, частицами и дрейфом фонового мира | Меши и материалы Babylon |
| `createGameScene` | Создаёт прозрачную ортографическую сцену и возвращает общий `GameHandle` | `Scene` и `GameWorld` |

## Контракт ассетов

Фон и декоративные DOM-ассеты берутся только по ссылкам из `ASSETS.md`. Геометрия игрока и мелкие точки создаются процедурно, так как они являются простыми формами без текстурной детализации.
